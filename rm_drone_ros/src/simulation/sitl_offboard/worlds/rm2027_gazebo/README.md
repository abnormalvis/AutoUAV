# RoboMaster 2027 赛场 Gazebo/SDFormat 仿真模型

依据《RoboMaster 2027 机甲大师高校系列赛机器人制作规范手册 V1.0.0（20261015）》
与《RoboMaster 2027 机甲大师超级对抗赛比赛规则手册》场地说明图纸生成。

## 目录

```
rm2027_gazebo/
├── CMakeLists.txt
├── package.xml
├── README.md
├── rm2027_arena.world              # 完整世界文件（含物理、光照、全部道具）
├── rm2027_field_topdown.png        # 赛场俯视参考图（28m x 15m）
├── rm2027_field_profile.png        # X 轴剖面参考图（高地/斜坡高度）

    ├── rm2027_field/               # 赛场静态模型（可独立 include）
    │   ├── model.config
    │   └── model.sdf
    └── rm2027_hangar/              # 空中机器人机库模型（600x300x400mm）
        ├── model.config
        └── model.sdf
```

## 快速启动

```bash
# 1. 放入工作区并编译（Gazebo Harmonic / Garden 推荐使用 sdformat13+）
mkdir -p ~/ws/src && cp -r rm2027_gazebo ~/ws/src/
cd ~/ws && colcon build --packages-select rm2027_gazebo
source install/setup.bash

# 2. 直接加载世界
gz sim -r $(ros2 pkg prefix rm2027_gazebo)/share/rm2027_gazebo/worlds/rm2027_arena.world

# 3. 或作为模型加载进自己的世界
#    在 ~/.gz/sim/<version>/server.config 的 <resource_paths> 中加入模型路径
#    <include><uri>model://rm2027_field</uri><pose>0 0 0 0 0 0</pose></include>
```

## 坐标系约定

| 轴 | 含义 | 正向 |
|---|---|---|
| X | 场地长轴（28m） | 蓝方 → 红方 |
| Y | 场地宽轴（15m） | 左 → 右（俯视） |
| Z | 高度 | 向上 |
| 原点 | 场地几何中心地面 | — |

所有道具坐标单位统一为 **米（m）**，碰撞体为包络长方体/圆柱，视觉尺寸与碰撞一致。

## 空中机器人仿真关键参数（规则 2.4.4）

| 项目 | 数值 | SDF 中的体现 |
|---|---|---|
| 运行方式 | 全自动，遥控器仅紧急停桨 | 建议用 `gz-sim-ros-control-system` + 自定义自主控制插件 |
| 最大供电总容量 | 4 Wh | 电池插件 `capacity=14400`（J） |
| 最大工作电压 | 30 V | 电路插件电压钳位 |
| 发射机构 | 不允许安装 | 不添加弹丸发射插件 |
| 最大重量 x | ≤ 0.249 kg | 惯性参数需自行按实机填入 |
| 最大伸展尺寸 | y = (0.3225−x)/0.001225，x∈[0.15,0.249]；x<0.15 时 y=141 | 碰撞体包络立方体边长 y（mm） |
| 桨保 | 全方向覆盖，孔径 < 17mm | 桨盘外扩圆柱壳，间隙网格尺寸 ≤ 15mm |
| 航行外观灯 | 顶面中心 7 颗 XL-3528SURUBC，圆形，包络圆 ≤ 24mm | 自发光材质 + 点光源，RGB #FF0000 / #0000FF |
| 自动停桨 | 失信号即停桨 | 控制插件超时检测 |

## 待补充项

1. **道具精确坐标**：官方《比赛规则手册》场地说明图纸（含各道具轮廓与坐标标注）尚未公开发布，
   本模型中道具位置为基于 2026 赛季图纸与 2027 规则描述的**示意布局**，正式使用需按官方图纸校准。
2. **视觉网格**：当前全部道具为 Box/Cylinder 占位体，建议用官方 STEP 场地图纸导出 `.dae`/`.stl`
   替换 `<visual><geometry>` 并保留现有 `<collision>`。
3. **弹丸/飞镖模型**：17mm 弹丸（0.035kg）、42mm 弹丸、飞镖（≤0.3915kg）需另建 `<model>` 并接入
   `gz-sim-projectile-system` 或自写弹道插件。
4. **裁判系统逻辑**：装甲模块受击、热量、血量、增益判定需自行实现系统插件，本模型仅提供碰撞体。
5. **起伏路段细节**：规则要求凸起按固定间距排布，当前仅用整块平台近似，需用 heightmap 或离散圆柱细化。
